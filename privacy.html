Privacy policy

Effective date: November 3, 2026

This policy covers the personal Google OAuth application “jornbowrl rclone”, operated by the owner of jornbowrl@gmail.com.

Google data accessed and purpose

The application requests Google Drive read/write access so rclone can list, read, download, upload, create, update, move, and delete files at the owner's direction. File contents and metadata are accessed only as needed for the commands the owner runs.

Storage and sharing

OAuth credentials and tokens are stored in the owner's local rclone configuration. Downloaded files and command output are stored at locations chosen by the owner. Uploads are transmitted from those chosen locations to Google Drive. Copy commands may transmit files to another destination explicitly selected by the owner.

This website does not receive or store OAuth tokens or Google Drive files. The operator does not sell Google user data, use it for advertising, or use it to train generalized AI or machine learning models. Data is not shared with other parties except as required to perform the owner's chosen transfers, comply with applicable law, or protect security.

Retention and control

Local credentials, logs, and copies remain until the owner removes them. Files in Google Drive remain subject to the owner's actions and Google's retention policies. To revoke access, remove this application from Google Account third-party connections. Revocation does not delete existing local file copies; those must be removed separately.

Security

Google API communication uses HTTPS. Credentials should be kept private and protected with local file permissions. No system can guarantee absolute security.

Google API Limited Use

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Website hosting

These static pages are hosted by GitHub Pages. The pages contain no application analytics, advertising, or tracking scripts. GitHub may process ordinary web request information under its own privacy policy.

Contact and changes

Questions or requests: jornbowrl@gmail.com. Changes to this policy will be posted here with an updated effective date.
